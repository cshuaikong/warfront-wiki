## Steam列出的配置是什么？

11月10日所查[主游戏](https://store.steampowered.com/app/5344530/WarFront/)和[试玩](https://store.steampowered.com/app/5503600/WarFront_Demo/)都列Windows，公开配置相同。先对照电脑，再诊断启动失败。这是规格，不是跑分，也不保证所有战斗规模都流畅。

| 项目 | 最低 | 推荐 |
| --- | --- | --- |
| 系统 | Windows 10，64位 | Windows 10或11，64位 |
| CPU | Intel Core i3或AMD Ryzen 3 | Intel Core i5或AMD Ryzen 5 |
| 内存 | 4096 MB | 8192 MB |
| GPU | DirectX 11、1 GB显存，Intel UHD 620或以上 | GTX 1050或RX 560，2 GB显存 |
| DirectX | 11 | 11 |
| 可用空间 | 1024 MB | 1024 MB |

平台标记未列macOS、Linux。参与者对Linux的猜测不能解释下面Windows案例，更不是Proton诊断。游戏列表只有英文；本站中文是自己的翻译，不是官方语言支持确认。

## 白屏报告究竟解决了什么？

[完整讨论](https://steamcommunity.com/app/5344530/discussions/0/568176624311253068/?l=english)里，楼主先说已检查驱动和文件，再澄清使用Windows。**11月9日21:58 UTC**，他报告安装从SSD移到HDD后可加载。所读帖子没有开发者确认的根因。

若测试另一处现有安装位置，把它当一条可回退、来自单人报告的线索。保留数据并记录改动；这里没有验证过的存档目录，也不要求买新硬盘。它不能证明SSD普遍失败，或相同做法能修好你的系统。

## 启动仍失败，应报什么？

记录系统、CPU/GPU、试玩安装状态、位置及窗口表现。附已尝试步骤，不把重复的驱动、文件检查说成新证明的修复。截图和启动过程可帮助区分白屏、控制或夜视问题。

在官方Steam讨论提交可复现案例，不分享密码、账号令牌或无关文件。现有来源未给核实的诊断日志目录。

真正进入对局后看[首次遭遇战控制](/zh/start/first-skirmish-and-controls/)；可玩但夜间难读看[夜视问题](/zh/support/night-vision-visibility/)；[访问范围说明](/zh/game-info/demo-release-and-modes/)分开免费试玩与未发售主游戏。

2026年11月10日核对，没有要求更换硬件、提供通用白屏解法、安装游戏或做帧率测试。
