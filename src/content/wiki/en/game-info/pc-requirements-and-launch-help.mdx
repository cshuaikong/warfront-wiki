## What hardware does Steam list?

Both the [main app](https://store.steampowered.com/app/5344530/WarFront/) and [Demo](https://store.steampowered.com/app/5503600/WarFront_Demo/) list Windows and the same requirements in the November 10 check. Compare your machine before diagnosing a failed launch. These are published specifications, not benchmarks or a smooth-performance guarantee for every battle size.

| Component | Minimum | Recommended |
| --- | --- | --- |
| OS | Windows 10, 64-bit | Windows 10 or 11, 64-bit |
| CPU | Intel Core i3 or AMD Ryzen 3 | Intel Core i5 or AMD Ryzen 5 |
| RAM | 4096 MB | 8192 MB |
| GPU | DirectX 11, 1 GB VRAM; Intel UHD 620 or better | GTX 1050 or RX 560, 2 GB VRAM |
| DirectX | 11 | 11 |
| Available storage | 1024 MB | 1024 MB |

The checked platform flags do not list macOS or Linux. A participant's Linux guess did not explain the Windows case below and is not a verified Proton diagnosis. The listing names English; this wiki's Chinese text is our translation, not official game-language confirmation.

## What did the blank-window report resolve?

In the [complete discussion](https://steamcommunity.com/app/5344530/discussions/0/568176624311253068/?l=english), the original reporter says drivers and files were checked, then clarifies Windows is in use. On **November 9 at 21:58 UTC**, they say moving the installation from SSD to HDD let it load. The inspected thread contains no developer-confirmed root cause.

If testing another existing installation location, treat it as a limited, reversible lead from one report. Preserve existing data and record the change. No verified save-folder path or need to buy another drive is provided here. This is not evidence that all SSDs fail or that the same move repairs your system.

## What should I report if launch still fails?

Record OS, CPU/GPU, installed Demo state, installation location and window behavior. Include checks already tried rather than presenting the same driver/file check as a newly proven repair. A screenshot and exact launch sequence help distinguish a blank window from a control or visibility complaint.

Use the official Steam discussion for a reproducible report. Do not share passwords, account tokens or unrelated files. The available sources do not supply a verified diagnostic log path.

Once a match opens, use [first-skirmish controls](/start/first-skirmish-and-controls/). For playable but unreadable night scenes, see [night vision](/support/night-vision-visibility/). The [availability guide](/game-info/demo-release-and-modes/) separates the free Demo from the unreleased main game.
